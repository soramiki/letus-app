### 4. 「LETUS」という名前を使わないことにした
- LETUSは東京理科大学が運営しているシステムの名前なので、アプリやURLの名前に使うと**大学の公式サービスと勘違いされる**おそれがある。
- そのため、次のようにした。
  - Vercelの Team Name・Project Name に使わない
  - GitHubのリポジトリ名を `letus-app` → **`task-manager`** に変更（Settings → Repository name → Rename）。Vercelとのつながりは切れなかった
  - READMEと画面の一番下に「**個人で作った非公式のツールです。東京理科大学およびLETUSとは関係ありません。**」と表示
- 機能の説明として「LETUSから取り込む」のように名前を出すのは問題ない。
- 手元のフォルダ名は `C:\dev\letus-app` のまま（自分のPCの中だけなので公開されない）。

### 5. 自動更新を確かめた（要項の条件）
- READMEを日本語に書き換え、画面の一番下に「非公式」の一文を足してPush。
- **約20秒で**、公開中のアプリにその一文が出た。

### 6. 検索・絞り込み・並び替えを作った（開発の順番「3」）
課題が1件以上あると、一覧の上に操作部分が出る。

| 機能 | 内容 |
| --- | --- |
| 検索 | 科目名か課題名に、入力した言葉が含まれる課題だけを出す（英字の大文字・小文字は区別しない） |
| 状態の絞り込み | 未完了／完了／すべて（最初は「未完了」） |
| 科目の絞り込み | 登録してある科目から選ぶ |
| 並び替え | 締切が近い順／締切が遠い順／科目順。どの順でも完了済みは下、締切未定は最後 |
| 件数の表示 | 「5件（全6件中）」のように表示 |
| 該当なし | 「条件をリセット」ボタンを出す |

- 架空の課題6件で、全部の組み合わせを試して確認。PCの広い画面で「未完了」の文字が2行に折れていたのを直した。
- 「科目順」は漢字の読み（五十音）の順にはならない。パソコンは漢字の読み方を知らないので、文字の番号順になる。同じ科目どうしがまとまって並ぶ役目は果たせている。

### 7. スマホで開いた
- 公開URLをスマホのブラウザで開くだけで使える（アプリのインストールは不要）。
- **データは端末ごと・ブラウザごとに別々**。同じiPhoneでも、SafariとChromeでは別の課題になる。
- iPhoneのChromeでは「ホーム画面に追加」が見つからなかったので、**Safariでホーム画面に追加**した。**ふだんはSafariで使う**ことにした。
- App Storeのアプリにするのは、作り方・費用・要項の点で今回は合わない。アプリのように使える形（PWA）は、開発の順番「6」で余裕があればやる。

## 📘 今日おぼえた言葉

- **デプロイ**：作ったアプリをインターネット上に置いて、使える状態にすること
- **noreply アドレス**：GitHubが用意する公開用のダミーのメールアドレス。本当のメールを隠せる
- **Hobby プラン**：Vercelの個人用・無料のプラン
- **Team Name**：Vercelの中での自分の作業場所の名前
- **自動デプロイ**：GitHubにPushすると、Vercelが自動で公開中のアプリを新しくしてくれる仕組み
- **PWA**：Webアプリを、スマホのアプリのように使えるようにする仕組み（全画面で開ける、アイコンが付く など）
