# 課題管理（仮）

大学の課題を、LETUSで出たものも口頭や紙で出たものもまとめて管理し、締切に遅れないようにするWebアプリです。

> **このアプリは個人で作った非公式のツールです。東京理科大学およびLETUSとは関係ありません。**

- 公開URL：https://task-manager-kappa-three-54.vercel.app/
- 開発中のため、内容は今後変わります。

## 概要

- 想定ユーザー：LETUSを使う大学生（スマホでの利用がメイン）
- 課題を「科目・課題名・締切」だけですばやく登録し、締切が近い順に確認できます。
- データはブラウザの中（LocalStorage）に保存します。ログインは不要です。

## 制作目的

- LETUSは開くたびにログインが必要で、通知もないため、課題に気づきにくい
- 口頭で言われた課題はLETUSに載らず、見落としやすい
- いつ始めるかを決めていないので、提出がギリギリになる

これらを、1か所で課題を管理できるようにすることで解決します。

## 主な機能

- 課題の追加・編集・削除
- 完了チェック
- 締切が近い順の表示、期限切れ・今日締切の色分け。課題の左の線と丸は科目の色（タイムラインと同じ）
- 開始日時の入力（任意）
- 検索（科目名・課題名）
- 絞り込み（未完了・完了・すべて／科目）
- 並び替え（締切が近い順・締切が遠い順・科目順）
- ホーム：今日の要約（期限切れ／今日締切／今日始める の件数。タップでその課題へ）
- 「始める日時」の自動計算（締切の2日前18時が基本）
- タイムライン：1科目1段で、締切を番号入りの丸（第〇回の数字）、開始〜締切を帯で表示。日付の行と科目の列はスクロールしても固定（今の線、土日の色分け。PCでは横幅いっぱい）
- LETUSの「カレンダーURL」を最初に1回保存すれば、次からはボタン1つで最新の課題を取り込める（ログイン不要）
- 取り込む前に「追加・更新・変更なし」の件数と内容を確認できる。開始と終了の予定は1件にまとめ、締切の延長にも対応。締切を過ぎた課題は「完了」にして取り込める
- 週の初めに、ホームで「LETUSの課題を取り込みましょう」とお知らせ
- 期限切れの課題を「提出できた／できなかった」で振り分け。できなかった回数を、ホームの右下の丸いボタンから科目ごとに見られる（回数で色が黄→オレンジ→赤に変わる）。その科目の課題に「⚠ これまでに〇回提出できていません」と注意を出す
- 毎朝の通知（7時ごろ）：今日締切・今日始める・期限切れの件数と課題名。件数は端末の中で数え、課題の内容はサーバーに送らない
- PWA：ホーム画面に追加すると、アプリとして全画面で開ける。電波がなくても開ける
- 再読み込みボタン（右上の ↻）：ホーム画面から開いたときも、新しい版に入れ替えて読み込み直せる
- 画面の下のタブで、ホーム／一覧／タイムライン／取り込みを切り替え

## 使用技術

- React 19
- Vite
- JavaScript
- CSS
- LocalStorage
- PWA（vite-plugin-pwa、Service Worker、Web App Manifest）
- Web Push（web-push、VAPID）／ Vercel Cron（毎朝の合図）／ Upstash Redis（通知の宛先だけを保存）
- IndexedDB（通知の件数を数えるための、課題の写し。端末の中だけ）
- Vercel Serverless Functions（LETUSのカレンダーを受け取る中継役 `api/letus-calendar.js`、通知の登録・送信 `api/push-*.js`・`api/cron-daily.js`）
- GitHub / Vercel

## ローカル環境での起動手順

Node.js が必要です。

```bash
git clone https://github.com/soramiki/task-manager.git
cd task-manager
npm install
npm run dev
```

ブラウザで http://localhost:5173 を開きます。
