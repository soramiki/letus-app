# 課題管理（仮）

大学の課題を、LETUSで出たものも口頭や紙で出たものもまとめて管理し、締切に遅れないようにするWebアプリです。

> **このアプリは個人で作った非公式のツールです。東京理科大学およびLETUSとは関係ありません。**

- 公開URL：https://task-manager-kappa-three-54.vercel.app/
- 開発中のため、内容は今後変わります。

## 概要

- 想定ユーザー：LETUSを使う大学生（スマホでの利用がメイン）
- 課題を「科目・課題名・締切」だけですばやく登録し、締切が近い順に確認できます。
- データはブラウザの中（LocalStorage）に保存します。ログインは不要です。

## 制作目的

- LETUSは開くたびにログインが必要で、通知もないため、課題に気づきにくい
- 口頭で言われた課題はLETUSに載らず、見落としやすい
- いつ始めるかを決めていないので、提出がギリギリになる

これらを、1か所で課題を管理できるようにすることで解決します。

## 主な機能

- 課題の追加・編集・削除
- 完了チェック
- 締切が近い順の表示、期限切れ・今日締切の色分け
- 開始日時の入力（任意）
- 検索（科目名・課題名）
- 絞り込み（未完了・完了・すべて／科目）
- 並び替え（締切が近い順・締切が遠い順・科目順）
- ホーム：今日の要約（期限切れ／今日締切／今日始める の件数。タップでその課題へ）
- 「始める日時」の自動計算（締切の2日前18時が基本）
- タイムライン：科目ごとに、開始〜締切を帯で表示（今の線、土日の色分け。スマホでは横スクロール、PCでは横幅いっぱい）
- LETUSの「カレンダーURL」を最初に1回保存すれば、次からはボタン1つで最新の課題を取り込める（ログイン不要）
- LETUSから書き出したカレンダー（.ics）ファイルの取り込みにも対応。取り込む前に「追加・更新・変更なし」の件数と内容を確認できる。開始と終了の予定は1件にまとめ、締切の延長にも対応。締切を過ぎた課題は「完了」にして取り込める
- 週の初めに、ホームで「LETUSの課題を取り込みましょう」とお知らせ
- 画面の下のタブで、ホーム／一覧／タイムライン／取り込みを切り替え
- サンプルの課題で試す（課題が0件のときにホームから。架空の授業名。まとめて消せる）

## 使用技術

- React 19
- Vite
- JavaScript
- CSS
- LocalStorage

- GitHub / Vercel

## ローカル環境での起動手順

Node.js が必要です。

```bash
git clone https://github.com/soramiki/task-manager.git
cd task-manager
npm install
npm run dev
```

ブラウザで http://localhost:5173 を開きます。

## 試し方

公開URLを開き、ホームの「サンプルの課題で試す」を押すと、架空の課題が入ります。終わったら「サンプルを消す」で消せます。

取り込みは、「取り込み」タブの「サンプル（架空）で試す」で、LETUSを使っていなくても試せます。「サンプルの .ics を保存」で試し用のファイルを保存して、ファイルを選ぶ流れも試せます。
